Javascript

JavaScript is a programming language which enables users to add interactivity to websites. This programming language enables users to have a web page that does things like presenting dynamic information, reacts to user activities, validating data entered on a form, and creating animations. I learned how JavaScript complements HTML and CSS, whereby HTML enables the creation of the structure of a web page while CSS handles the styling of a web page. Through JavaScript learning, I have acquired knowledge about variables, functions, events, and programming logic. In addition, I have learned how JavaScript enables a web page to be updated without forcing the user to refresh the site.
